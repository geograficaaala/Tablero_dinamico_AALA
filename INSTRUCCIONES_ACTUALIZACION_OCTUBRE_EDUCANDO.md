# Educando para Conservar — actualización de octubre de 2026

Instalación:

1. Descomprimir este ZIP y copiar su contenido a la raíz del repositorio `Tablero_dinamico_AALA`, manteniendo exactamente las rutas.
2. Confirmar los ocho archivos de código, tablas y pruebas, y hacer commit en `main`.
3. Verificar el Action `Validar datos y módulos — Educando para Conservar`.
4. Ejecutar o verificar `Publicar dashboards AALA` y recargar la página de Educando para Conservar y el índice.

Comprobaciones locales: 108 de 108 pruebas JavaScript superadas y los seis validadores Python ejecutados correctamente.
